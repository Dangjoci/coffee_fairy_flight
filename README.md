# ☕ 향기 순찰 — 커피요정 비행

커피요정이 노을 진 바다와 산 위를 나는 도트풍 3D 비행 게임입니다.
무궁화를 모으고, 졸음 구름은 원두펀치로 깨우세요.

**▶ 바로 플레이: https://dangjoci.github.io/coffee_fairy_flight/**

## 조작

| 동작 | 컴퓨터 | 폰 |
|---|---|---|
| 조종 | 마우스 방향 (또는 WASD / 방향키) | 화면 끌기 |
| 부스트 — 엉덩이에서 원두 발사 | 마우스 길게 누르기 (또는 Shift) | 부스트 버튼 |
| 원두펀치! | F (또는 오른쪽 클릭) | 펀치 버튼 |
| 빙글 돌기 | 짧게 클릭 (또는 R) | 빙글 버튼 |
| 시점 바꾸기 | Space | 시점 버튼 |

시점은 하늘에서 · 추격 · 요정 눈 · 한바퀴, 4가지입니다.

## 점수

- 무궁화 고리 통과: 1점
- 졸음 구름 원두펀치: 3점
- 결점두(상한콩), 디카페인 잔 원두펀치: 2점
- 원두수리검(옆으로 미끄러지며 돎), 원두탄환(곧게 날아감) 원두펀치: 4점
- 중절모 원두펀치: 5점

원두펀치에 맞은 것은 층 단위 판으로 부서져 흩어집니다.

## 파일

`index.html` 하나에 게임 전체가 들어 있습니다(Three.js r128 포함). 내려받아 브라우저로 열면 인터넷 없이도 실행됩니다.

## 적층 복셀

커피요정, 무궁화 고리, 졸음 구름, 원두, 부술 것들, 건물, 뭉게구름, 산과 바다까지 모두 적층 픽셀(sprite stacking) 방식의 복셀로 그립니다.
물체를 수평으로 얇게 썬 도트 층을 격자로 깔아 놓은 PNG(층 아틀라스)가 `index.html` 안에 들어 있고, 게임이 시작할 때 이를 읽어 두께 있는 복셀로 세웁니다.

- 색은 부위마다 4단계입니다. 밝은 쪽은 노랗게, 어두운 쪽은 붉은 보라로 색상을 틀고, 빛 방향과 파묻힌 정도로 단계를 고릅니다.
- 물체마다 어두운 외곽선이 둘립니다(살짝 부풀린 껍데기의 안쪽 면을 깊이만 뒤로 밀어 그림).
- 출발 지점 앞 육지에는 평평한 터를 내어 카페 요정의집과 로스팅 공장을 세웠습니다.

`voxel/` 폴더는 그 층 아틀라스를 만드는 원본입니다. 게임 실행에는 필요 없습니다.

- `models.py` — 무궁화 고리·졸음 구름·원두·건물(요정의집, 로스팅 공장)·부술 것들(결점두, 디카페인 잔, 원두수리검, 원두탄환, 중절모) 모델과 자동 칠하기. 건물 외형은 시안입니다.
- `fairy/` — 커피요정 모델을 만든 스크립트. 360° 캐릭터 시트의 여덟 실루엣으로 형태를 깎고(`extract_views.py`, `prior.py`, `build3.py`), 얼굴은 직접 그리고, 비행 자세와 날갯짓 3프레임으로 바꿉니다(`flight.py`). 다시 돌리려면 캐릭터 시트 그림이 필요하며, 시트는 저장소에 넣지 않았습니다.
- `stackpix.py` — 복셀 모델을 한 줄 스트립·회전 미리보기로 내보내는 도구
- `*_strip.png`, `meta.json` — 내보낸 층 아틀라스와 크기·원점 정보

`커피요정_도트시트_8방향.png`는 예전 도트 그림판 방식에서 쓰던 그림으로, 지금 게임에서는 쓰지 않습니다.
