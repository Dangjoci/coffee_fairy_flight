# ☕ 향기 순찰 — 커피요정 비행

커피요정이 노을 진 바다와 산 위를 나는 도트풍 3D 비행 게임입니다.
무궁화를 모으고, 졸음 구름은 원두펀치로 깨우세요.

**▶ 바로 플레이: https://dangjoci.github.io/coffee_fairy_flight/**

## 조작

| 동작 | 컴퓨터 | 폰 |
|---|---|---|
| 조종 | 마우스 방향 (또는 WASD / 방향키) | 화면 끌기 |
| 부스트 — 엉덩이에서 원두 발사 | 마우스 길게 누르기 (또는 Shift) | 부스트 버튼 |
| 원두펀치! | F (또는 오른쪽 클릭) | 펀치 버튼 |
| 빙글 돌기 | 짧게 클릭 (또는 R) | 빙글 버튼 |
| 시점 바꾸기 | Space | 시점 버튼 |

시점은 하늘에서 · 추격 · 요정 눈 · 한바퀴, 4가지입니다.

## 점수

- 무궁화 고리 통과: 1점
- 졸음 구름 원두펀치: 3점

## 파일

`index.html` 하나에 게임 전체가 들어 있습니다(Three.js r128 포함). 내려받아 브라우저로 열면 인터넷 없이도 실행됩니다.

## 적층 복셀

커피요정, 무궁화 고리, 졸음 구름, 원두, 뭉게구름, 산과 바다까지 모두 적층 픽셀(sprite stacking) 방식의 복셀로 그립니다.
물체를 수평으로 얇게 썬 도트 층을 한 줄로 이어 붙인 PNG(층 스트립)가 `index.html` 안에 들어 있고, 게임이 시작할 때 이를 읽어 두께 있는 복셀로 세웁니다.

`voxel/` 폴더는 그 층 스트립을 만드는 원본입니다. 게임 실행에는 필요 없습니다.

- `models.py` — 요정(비행 자세, 날갯짓 3프레임)·무궁화 고리·졸음 구름·원두 모델. 요정 치수는 캐릭터 시트에서 잰 값입니다.
- `stackpix.py` — 복셀 모델을 층 스트립·회전 미리보기로 내보내는 도구
- `*_strip.png`, `meta.json` — 내보낸 층 스트립과 크기·원점 정보

`커피요정_도트시트_8방향.png`는 예전 도트 그림판 방식에서 쓰던 그림으로, 지금 게임에서는 쓰지 않습니다.
